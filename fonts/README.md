# Test font

[JetBrains Mono](https://www.jetbrains.com/lp/mono/) (Regular, Medium,
Bold), licensed under the SIL Open Font License 1.1. The tests load it as a
real typeface for their layout checks (`test/demo_support.dart`): the
default flutter_test font draws every glyph a full em wide. The app does
not bundle it.
